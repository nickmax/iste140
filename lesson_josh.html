Lesson 1: How Multiplayer Games Connect (Ping, Latency & Servers)

Author: Josh (HTML Lead)

1. What is Latency and Ping?

When you press a button in an online game, your action doesn't hit the screen instantly. There's more to it. Latency is the time it takes for a packet of data to travel from your computer or console out to the game server and back. In gaming, we measure this round trip in milliseconds (ms) and call it your ping.

  • 0 to 30 ms: Ideal connection. Everything feels super fast.
  • 31 to 80 ms: Standard playable connection. You might feel a little delay, but it's barely going to affect the gameplay.
  • 80 to 150+ ms: High latency. This is where it gets annoying, you see delayed shots, ghost hits, and similar experiences.

2. How Data Travels: UDP vs. TCP

When you visit a website or download a file, your browser uses TCP (Transmission Control Protocol) because every single byte of data has to arrive in order without any errors. Fast-paced multiplayer games use UDP (User Datagram Protocol) instead. UDP focus more on raw speed. It focuses on player positions constantly and keeps going even if a few packets get lost along the way, all that to avoid game pauses.

3. Server Tick Rates Explained

A server's tick rate is how many times per second the game server processes actions and updates the match state for everyone:

  1. The server gathers input data (movement, shots fired) from all connected players.
  2. It calculates player movement, physics, and hit detection.
  3. It broadcasts the updated world state back out to every player's device.

The classic 64-tick server updates 64 times every second (~15.6 ms per tick). Competitive games usually use 128-tick servers (~7.8 ms per update), which makes movement feel very smooth and hit detection a lot more accurate.
