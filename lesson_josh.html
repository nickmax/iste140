Lesson 1: How Multiplayer Games Connect (Ping, Latency & Servers)

Author: Josh (HTML Lead)

1. What is Latency and Ping?

In online gaming, latency refers to the total time it takes for a data packet to travel from your gaming device (the client), reach the game server, and send back a response. This duration is measured in milliseconds (ms) and is commonly referred to as your ping.

  • 0 to 30 ms: Optimal connection. In-game actions feel instant.
  • 31 to 80 ms: Playable connection. Slight delay, rarely noticeable in casual play.
  • 80 to 150+ ms: High latency. Rubberbanding, delayed shots, and visual desync occur.

2. How Data Travels: UDP vs. TCP

Websites use TCP (Transmission Control Protocol) because every single piece of data must arrive accurately without losing a byte. Multiplayer games, however, use UDP (User Datagram Protocol). UDP prioritizes raw speed over absolute reliability, allowing games to fire constant streams of position updates without waiting to re-transmit lost packets.

3. Server Tick Rates Explained

A server's tick rate measures how many times per second the game server processes game logic and broadcasts the updated world state back to every connected player:

  1. The server collects player inputs (movement, firing).
  2. The server simulates physics and checks for collisions or damage.
  3. The server broadcasts the updated positions to all players.

A 64-tick server updates 64 times every second (~15.6 ms per tick), whereas a competitive 128-tick server updates 128 times every second (~7.8 ms per tick), delivering far more responsive gameplay.
